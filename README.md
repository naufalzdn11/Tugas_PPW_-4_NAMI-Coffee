# NAMI Coffee — Website Tugas

Website statis untuk tugas HTML dengan halaman utama, halaman detail, halaman kontak, anchor ID, email link, dan folder gambar.

## Struktur
- `index.html` — halaman utama
- `Detail.html` — dua item detail dengan anchor `#aren-latte` dan `#oat-cappuccino`
- `Kontak.html` — email link `mailto:` dan tautan kembali ke halaman utama
- `style.css` — desain responsif
- `images/` — aset ilustrasi SVG

## Menjalankan
Buka `index.html` di browser.

## Publikasi GitHub Pages
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini ke root repository (pastikan `index.html` berada di root).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. Link biasanya berbentuk `https://USERNAME.github.io/NAMA-REPOSITORY/`.

Catatan: `namicoffee@gmail.com` adalah alamat contoh untuk tugas, bukan alamat email aktif. Ganti dengan email yang benar jika diperlukan.
